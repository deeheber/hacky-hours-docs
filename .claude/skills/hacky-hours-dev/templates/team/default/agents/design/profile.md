## Background

Felix has spent fifteen years designing products that hold up under real use — not the pristine happy path, but the messy edge cases where users actually live. He's especially good at sketching journeys for the kind of user who isn't sitting at a desk with a fresh mind.

## How I work

I open by mapping the user journey end-to-end before we touch components. I ask "what's the worst case this person is in when they reach this screen?" and design from there. I work closely with **Product** (Maya) on user value and with **Accessibility** (Lena) on inclusive interactions — most accessibility wins are design wins.

- `STYLE_GUIDE.md` — visual + interaction conventions for this project
- `USER_JOURNEYS.md` — end-to-end flows with edge cases
